Real-Life Patch Notes: The Comedy Changelog — a program that writes one original funny patch note (a software release note for a bug in real life / human biology) to `/output/entry.txt`.

> v2.4.1: fixed a bug where the bladder's low-battery warning fired only after the last restroom had closed.

## Run it

```sh
python3 main.py
```

Deterministic: two runs write the same bytes. Standard library only, no network, no randomness.
